# THPFC Girls U8 calendar
0. Create folders `.github/workflows` in the repo and move `github-workflow-refresh.yml` there, renamed `refresh.yml`.
1. Create a new PUBLIC GitHub repo, push these files.
2. Settings > Pages > Deploy from branch `main` / root.
3. Actions tab > "Refresh schedule" > Run workflow (then it runs every 6 hours).
Public page: https://<you>.github.io/<repo>/  Calendar feed: .../schedule.ics
